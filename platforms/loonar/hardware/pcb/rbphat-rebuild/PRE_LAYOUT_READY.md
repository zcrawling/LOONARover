# RBPHAT B2 — 아트웍 착수 인계

2026-09-05. 회로도·품번·로컬 풋프린트·기구 기준·PCB 시작 파일을 준비했다. **부품 배치와 배선은 아직 시작하지 않았다.** 최신 기준은 이 문서와 현재 KiCad 파일이며, B1 및 1·2단계 문서는 변경 이력이다.

## 검증 결과

- 회로도 4장, 72개 항목, 240개 핀 연결 확인. ERC 오류 0 / 경고 0.
- PCB와 회로도의 일치 검사 문제 0. 현재 시작 파일의 DRC 위반 0, 미연결 161개. 미연결은 아트웍 단계에서 전부 해소해야 한다.
- 회로 풋프린트 72개와 장착홀 4개. 헤더와 홀만 기구 위치에 고정하고, 나머지 71개는 보드 밖에 대기시켰다. 트랙·비아·구리 채움은 없다.
- 사용 풋프린트 15종을 프로젝트에 고정했다. TI IC, Bourns TVS, Panasonic 전해콘덴서의 제조사 랜드 패턴을 대조했다. 일반 0603은 단자 치수와 겹침을 검토한 KiCad 패턴이다.
- 실장 구매 부품 63개, 선택 실장 저항 2개(DNP), PCB 테스트 포인트 7개. 구매 부품 품번을 채웠으며 재고·가격·납기 확인은 포함하지 않는다.

## 확정된 기구 조건

사용자는 공식 Raspberry Pi Active Cooler와 PRT-16763의 **16mm 몸체 유지, 스페이서 높이 변경**을 선택했다. 이를 반영해 보드 간격과 M2.5 스페이서를 공칭 **19mm**로 설정했다. 16mm를 PCB 간격으로 해석한 이전 표기는 폐기한다.

Pi 수 헤더 몸체 약 2.5mm와 노출 핀 약 6mm 기준으로 공칭 삽입 길이는 5.5mm다. Cooler 참고 높이 13.7mm 대비 높이 여유는 약 5.3mm다. 이는 도면 기반 공칭 검토이며, 헤더 공차·접점 유지·나사 체결은 첫 조립 때 확인한다. 아래쪽에는 J1 소켓 이외 회로 부품을 두지 않는다. Cooler 흡입과 케이블 접근을 최종 배치·조립에서도 확인한다.

보드는 65×56mm, 모서리 R3, 장착홀 지름 2.75mm, 홀 간격 58×49mm다. KiCad 원점 기준 보드 좌상단은 (100,100)mm, 홀 중심은 (103.5,103.5), (161.5,103.5), (103.5,152.5), (161.5,152.5)mm다. 각 홀에 지름 6.2mm 나사 구리 금지 영역을 설정했다. J1 핀 1은 (108.37,104.77), 핀 2는 (108.37,102.23)mm이며 뒷면 실장 방향을 반영했다.

기구 부자재 치수 BOM: M2.5 암/암 19mm 스페이서 4개, 대응 M2.5 나사 8개. 나사 길이는 실제 보드·와셔 두께 및 스페이서 유효 나사 깊이에 맞춰 조립 시 결정한다. 전기 부품 BOM과 별도이며 특정 기구품 공급사 품번을 검증한 것은 아니다.

HAT 측 케이블 부품: JST GHR-05V-S 2개, GHR-02V-S 1개, SSHL-002T-P0.2 단자 12개와 작업 여유분. AWG 30–26 / 피복 외경 0.76–1.0mm 범위. 원격 단부와 케이블 길이는 포함하지 않는다.

[기구 검토 PDF](mechanical-review.pdf), [풋프린트 검토 PDF](footprint-review.pdf). 3D 파일은 KiCad 모델 및 자체 헤더 외형 모델이며 실측 조립 검증을 대신하지 않는다.

## 회로 및 펌웨어 기준

전이중 통신은 THVD1451DR 2개와 SN74LVC2G17DBVR 버퍼를 사용한다. 통신 커넥터 J2/J3은 1 TX+, 2 TX−, 3 RX+, 4 RX−, 5 GND다. 원격 장치에는 TX/RX pair를 교차 연결한다. 수신 120Ω R107/R207은 DNP이며 실제 케이블과 원격 종단 조건에 맞춰 선택한다. TVS는 Bourns CDSOT23-SM712, JST는 상향 삽입 BM 계열이다. 초기 MAX3490E·Semtech·측면 SM 계열 표는 사용하지 않는다.

배터리는 정상 극성 0–12.6V, 공통 GND 조건이다. 수정 분압 환산 계수는 **8.222222**이며 이전 6.222222를 사용하지 않는다. ADS1115 주소 0x48, AIN0 단일 입력, PGA ±4.096V, 예시 설정 0xC383, signed 16-bit 해석을 사용하고 POWER_GOOD 후 150ms 이상 기다린다. 12.6V에서 계산상 ADC 로딩 편차는 약 −23.5mV이며 사용자가 허용한 약 33mV 범위다. 전체 오차 보증과는 구분한다.

전원 차단 격리는 LM66100, TLV803E, TMUX1511, TCA9517A와 아날로그 홀드업으로 구성했다. 세부 계산과 핀 근거는 [회로 검토 이력](DESIGN_REV_B.md), [계산](rev_b_calculations.json)에 있다. 고속 차단 과도응답과 EMC/서지는 시제품 시험 항목이다. 역극성 배터리·자동차 load dump 보호나 HAT+ 인증을 주장하지 않는다.

## 아트웍에서 적용할 조건

4층, 총 두께 1.6mm, 구리 각 35µm의 시작 설정이다. F.Cu 신호·부품, In1.Cu 연속 GND, In2.Cu 전원, B.Cu 신호·GND를 기본으로 한다. 현재 유전체 두께와 유전율은 설계 초기값이며 제작업체 확정 적층이나 임피던스 보증 값이 아니다.

최소 선폭/간격 0.2mm, 일반 선폭 0.25mm, 전원 시작 선폭 0.5mm, 비아 0.6/0.3mm, 구리-외곽 0.3mm를 설정했다. 차동쌍 0.25mm 폭/0.2mm 간격은 초기값으로, 필요한 임피던스는 제작업체 적층에 맞춰 계산한다.

배치 순서: 커넥터와 TVS → 통신 IC/직렬저항 → 전원 격리/디커플링 → ADC/분압/TMUX → 테스트 포인트. TVS는 커넥터 가까이 두고 GND 귀환을 짧게 한다. 디커플링은 IC 전원 핀에 밀착하고 ADC 입력은 통신선·전원 스위칭 경로에서 분리한다. 커넥터 삽입 공간과 나사 공구 공간을 남긴다.

아트웍 완료 조건: 모든 회로 부품 보드 내 배치, 구리 채움과 배선 완료, 미연결 0, ERC/DRC/회로도 일치 재검증, 실크 극성·핀 1·커넥터 방향 확인, 최종 3D 조립 확인, 제조사 적층/공차 반영 후 제조 파일 생성. 현재 파일로 제조 주문하지 않는다.

## 재생성

`prepare_layout.py` → `generate_schematic.py` → `validate_schematic.py` → `create_board_start.py` → `finalize_board_start.py` → KiCad DRC → `validate_prelayout.py` 순서다. PDF 검토표는 `render_prelayout.py`로 생성한다. **create_board_start.py는 PCB를 초기화하므로 아트웍 착수 후 실행하지 않는다.** 이 호스트에서는 KiCad/pcbnew 실행 시 `LD_LIBRARY_PATH=/usr/lib/x86_64-linux-gnu`를 사용한다.
