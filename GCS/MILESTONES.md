# GCS 개발 마일스톤

목표는 Wi-Fi AP를 통해 영상, 차량 제어·상태, ROS 디버깅의 세 경로를 운용하는 것이다. 이 문서는 개발 계획이며 실제 구현·시험 완료를 뜻하지 않는다. 일정은 장비 준비와 각 단계 결과를 확인한 뒤 정한다.

모든 파일 생성·수정은 `LOONARover/GCS/` 내부에서만 수행한다. 로버나 AP 설정 변경이 필요한 항목은 별도 작업 의존성으로 기록한다.

## 전체 구성

```text
라즈베리파이                       Wi-Fi AP                지상국 PC
카메라 → H.264/MPEG-TS ───────── UDP 5600 ────────────→ 영상 플레이어
cFS GroundLink        ←──────── TCP 7443 ────────────→ GCS 백엔드 ↔ UI
ROS 2                 ───────── DDS 관측 데이터 ─────→ RViz2·조회 도구
```

세 경로는 통신 처리상 독립적이지만 같은 무선 대역폭을 공유한다. 영상·지도 전송 중에도 조작 응답을 함께 확인한다.

## M0 — 연결 대상과 개발 환경 확인

- [ ] GCS PC, 로버, AP를 준비하고 로버 IP와 지상국 IP를 기록한다.
- [ ] `README.md`와 `../docs/ground_link_protocol.md`를 확인한다.
- [ ] GCS 내부에 `.gitignore`, `requirements.txt`, `.env.example`을 준비한다.
- [ ] 실제 주소는 로컬 `.env`에 두고 소스에 고정하지 않는다.
- [ ] 로버의 cFS GroundLink 실행 여부와 TCP 7443 접속 가능 여부를 확인한다.

**완료 기준:** 접속 대상과 설정 방법이 명확하며, TCP 서버에 접근할 수 있다. 장비가 준비되지 않아도 M1은 진행할 수 있다.

## M1 — GroundLink 프로토콜 구현

**첫 번째 코딩 작업이다.**

- [ ] `backend/protocol.py`: 헤더와 명령 프레임 인코더를 구현한다.
- [ ] 상태·명령 결과 프레임 디코더를 구현한다.
- [ ] TCP 수신 버퍼에서 완성된 프레임만 추출하는 파서를 구현한다.
- [ ] `tests/test_protocol.py`, `tests/test_stream_parser.py`를 작성한다.

**완료 기준:** 로버 없이 아래 테스트를 통과한다.

- 헤더·본문이 나뉘어 도착하는 경우와 여러 프레임이 함께 도착하는 경우
- 잘못된 magic/version/type, 최대 크기를 넘는 payload, 잘못된 고정 길이 거부
- MANUAL 선속도·각속도 인코딩과 디코딩 왕복

## M2 — TCP 상태 수신

- [ ] `backend/config.py`: 연결 설정을 읽는다.
- [ ] `backend/rover_client.py`: 연결 하나를 유지하며 수신·재접속을 처리한다.
- [ ] `backend/state.py`: 최신 상태, 수신 시각, 연결 상태를 저장한다.
- [ ] 현재 모드·배터리·수신 시각을 터미널에서 확인한다.
- [ ] 연결 단절 시 이전 상태를 오래된 데이터로 구분한다.

**완료 기준:** 실제 로버의 GatewayStatus와 VehicleStatus를 수신하고, Wi-Fi 복구 후 다시 수신한다. 연결·재접속 시 자동으로 모드 변경 명령을 보내지 않는다.

## M3 — 상태 표시 화면

- [ ] `backend/app.py`: FastAPI의 `/api/health`, `/api/state`를 구현한다.
- [ ] `web/index.html`, `web/app.js`, `web/style.css`: 기본 화면을 구현한다.
- [ ] 백엔드·TCP 연결 상태, 실제 모드, 마지막 수신 시각을 표시한다.
- [ ] 배터리, 온도, 센서·MCU·Wi-Fi 상태는 수신 데이터와 유효 여부에 따라 표시한다.
- [ ] 아직 제공되지 않는 값은 `—`로 표시한다.

**완료 기준:** 브라우저에서 상태를 확인할 수 있고, 정상·미제공·연결 단절 상태를 구별할 수 있다. 초기에는 1초 주기 조회로 시작한다.

## M4 — 명시적 명령과 결과 확인

- [ ] STOP, AUTO, MANUAL 순서로 API와 버튼을 연결한다.
- [ ] 명령별 sequence와 응답 대기 상태를 기록한다.
- [ ] 로버의 COMMAND_RESULT를 요청과 연결해 표시한다.
- [ ] 수동 모드 선택은 명시적인 `MANUAL(0, 0)` 요청으로 시작한다.
- [ ] PAYLOAD·REACTION 요청 형식과 결과 표시를 추가한다. opcode 의미는 임의로 만들지 않는다.

**완료 기준:** 로컬 HTTP 접수와 로버 응답을 구별하며, 실제 모드는 로버 상태로 표시한다. 미구현 기능의 `NOT_IMPLEMENTED`를 연결 오류와 구별한다.

## M5 — 수동 조이스틱 조종

- [ ] 조이스틱 입력을 선속도와 각속도로 변환한다.
- [ ] 화면에 표시한 값과 동일한 MANUAL 명령을 보낸다.
- [ ] 입력 전송 주기와 버튼 해제·중립 입력 동작을 명시하고 검증한다.
- [ ] STOP 버튼을 항상 보이도록 배치한다.
- [ ] 운영자가 승인한 조건에서 수동 조종과 명시적 STOP을 확인한다.

**완료 기준:** 조이스틱 입력, 전송 값, 로버 응답을 비교할 수 있다. UI가 숨겨진 모드 변경이나 명령 재작성을 수행하지 않는다.

## M6 — 독립 영상 수신

- [ ] ffplay 또는 GStreamer로 UDP 5600 영상을 수신한다.
- [ ] 로버 송신기의 1/3/5 Mbps 프리셋별 수신 결과를 기록한다.
- [ ] 영상 지연·끊김과 동시 제어 응답을 확인한다.
- [ ] 영상 중단 시에도 TCP 상태 수신·명령 경로가 동작하는지 확인한다.

**완료 기준:** 선택한 영상 프리셋으로 지속 수신하며, 영상과 제어를 동시에 사용할 수 있다. 브라우저 내 영상 삽입은 후속 선택 항목이다.

**의존성:** 로버 카메라 송신기와 프리셋 설정이 준비되어야 한다. GCS 외부 설정 파일은 이 작업에서 변경하지 않는다. M2 이후 독립적으로 확인해도 된다.

## M7 — ROS 읽기 전용 디버깅

- [ ] GCS 앱과 별도 프로그램으로 ROS 2/RViz2 관측 환경을 준비한다.
- [ ] AP를 통한 DDS 검색·통신과 양쪽 ROS 설정 호환성을 확인한다.
- [ ] odom·TF를 표시한다.
- [ ] 누적 이동경로, 2.5D 지도, 내부 파라미터를 조회한다.
- [ ] 관측 토픽의 주기·데이터 크기·QoS를 기록한다.

**완료 기준:** 지상국에서 필요한 데이터를 읽으며, 디버깅 경로로 주행 명령이나 파라미터 변경을 보내지 않는다.

**의존성:** 누적 경로 생성 노드, 2.5D 지도 생성 노드와 해당 지도 형식의 표시 도구가 필요하다. 없는 데이터 생산부는 별도 로버 작업으로 기록한다.

## M8 — 세 경로 통합 확인과 운용 문서

- [ ] 영상·제어·ROS 관측을 동시에 실행한다.
- [ ] 명령 왕복 시간, 상태 수신 간격, 영상 지연·끊김을 기록한다.
- [ ] 큰 지도 전송과 각 영상 프리셋에서 제어 응답 변화를 확인한다.
- [ ] 링크 단절 시 로버 동작을 실제 구현 기준으로 확인하고 기록한다.
- [ ] Wi-Fi 복구 후 재접속과 상태 갱신을 확인한다.
- [ ] GCS 내부에 실행·종료·설정·문제 진단 방법을 정리한다.

**완료 기준:** 운영자가 합의한 응답·영상 품질 기준을 만족하고, 다른 사람이 문서만으로 재현할 수 있다. TCP 자체가 실시간 응답이나 링크 단절 시 정지를 보장한다고 가정하지 않는다.

## 첫 착수 범위

M0의 문서·폴더 확인과 M1부터 시작한다. 첫 결과물은 **프로토콜 코드와 통과한 파서 테스트**이고, 첫 실제 장비 목표는 **M2의 상태 수신 및 재접속**이다.

```text
M0 준비 → M1 프로토콜 → M2 상태 수신 → M3 화면 → M4 명령 → M5 조이스틱
                          ├→ M6 영상
                          └→ M7 ROS 관측
                                  ↓
                            M8 통합 확인
```
