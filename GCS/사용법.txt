LOONAR 지상국 사용법
====================

이 문서는 처음 사용하는 사람이 GitHub에서 프로젝트를 받은 뒤
로버와 지상국을 순서대로 실행하는 방법을 설명합니다.


1. 먼저 알아둘 점
-----------------

이 시스템에는 컴퓨터가 두 대 필요합니다.

  1) 지상국 PC
     - 웹 지상국, 진단 화면, 영상 수신 창을 실행합니다.

  2) 로버 PC
     - ROS 2, LIMO 드라이버, Gateway, cFS, 영상 송신을 실행합니다.

두 컴퓨터는 같은 Wi-Fi에 연결되어 있어야 합니다.

GCS 저장소를 다운로드하는 것만으로 새 로버의 모든 프로그램이
설치되지는 않습니다. 로버에는 다음 항목이 미리 준비되어 있어야 합니다.

  - /opt/ros/humble
  - $HOME/agilex_ws
  - $HOME/loonar_ws
  - $HOME/loonar_cfs
  - loonar-video.service


2. 지상국 PC에 프로젝트 다운로드
-------------------------------

터미널을 열고 다음 명령을 순서대로 실행합니다.

  cd ~
  git clone https://github.com/zcrawling/LOONARover.git
  cd LOONARover/GCS

이미 다운로드했다면 다시 clone하지 않고 다음처럼 최신 코드를 받습니다.

  cd ~/LOONARover
  git pull
  cd GCS


3. 지상국 PC의 기본 프로그램 확인
---------------------------------

다음 명령이 모두 실행되는지 확인합니다.

  python3 --version
  ssh -V
  ffplay -version
  gnome-terminal --version

각 프로그램의 역할은 다음과 같습니다.

  - python3: 웹 지상국과 진단 프로그램 실행
  - ssh: 로버 원격 접속
  - ffplay: UDP 5600 영상 수신
  - gnome-terminal: 진단 창과 영상 창 자동 실행

Git으로 받은 셸 스크립트는 실행 권한이 유지되므로 일반적으로
chmod 명령은 필요하지 않습니다.


4. 로버 IP 확인
---------------

로버와 지상국 PC를 같은 Wi-Fi에 연결합니다.

로버 IP가 192.168.1.50이라고 가정하면 지상국 PC에서 다음처럼 확인합니다.

  ping -c 3 192.168.1.50

반드시 192.168.1.50을 현재 로버의 실제 IP로 바꿔 입력합니다.

응답이 오면 네트워크에서 로버에 도달할 수 있는 상태입니다.


5. 로버 시작
------------

지상국 PC의 첫 번째 터미널에서 실행합니다.

  cd ~/LOONARover/GCS
  bash scripts/start_rover.sh

SSH 주소를 물으면 다음 형식으로 입력합니다.

  로버계정@로버IP

예시:

  rover@192.168.1.50

실제 로버 계정과 IP로 바꿔야 합니다.

필요하면 SSH 암호를 입력합니다. 영상 송신 설정을 변경해야 하는 경우에는
로버의 sudo 암호를 추가로 물을 수 있습니다.

이 스크립트는 로버에서 다음 순서로 준비 상태를 확인합니다.

  1) limo_base
  2) vehicle_gatewayd
  3) loonar_limo_backend
  4) core-cpu1
  5) 영상 송신 서비스

각 항목에 "준비 완료"가 표시되면 정상입니다.

로버 시작 터미널은 사용하는 동안 닫지 않는 것이 좋습니다.


6. 지상국 시작
--------------

지상국 PC에서 새 터미널을 하나 더 열고 실행합니다.

  cd ~/LOONARover/GCS
  bash scripts/start_gcs.sh

로버 IP를 물으면 현재 로버 IP를 입력합니다.

정상적으로 실행되면 다음 세 화면이 자동으로 열립니다.

  1) 웹 지상국
     - 명령 전송과 로버 상태 확인에 사용합니다.

  2) 진단 터미널
     - 네트워크, SSH, GroundLink, 데이터 수신, 로버 프로그램 상태를
       확인합니다.
     - 위쪽에는 상태 변경 이력, 아래쪽에는 현재 상태가 표시됩니다.

  3) 영상 수신 창
     - 로버가 UDP 5600으로 보내는 영상을 표시합니다.

웹 브라우저가 자동으로 열리지 않으면 다음 주소를 직접 엽니다.

  http://127.0.0.1:8080


7. 정상 연결 확인
-----------------

웹 지상국에서 다음 항목을 확인합니다.

  - REAL ROVER / 로버 IP
  - TCP CONNECTED
  - 마지막 메시지가 약 0~1초 전
  - RX 숫자가 계속 증가
  - 데이터 누락 구간 0

이 조건이면 Mock 데이터가 아니라 실제 로버 데이터를 받고 있습니다.

ROS 데이터 영역에는 로버 내부 ROS를 거쳐 전달된 배터리, Odometry,
속도, IMU 값이 표시됩니다.


8. 로버 조종
------------

웹 지상국의 명령 버튼을 사용합니다.

  - STOP: 즉시 정지 모드 요청
  - MANUAL: 수동 조종 모드 전환
  - AUTO: 자동 모드 전환

수동 조종 키:

  - 위쪽 방향키 또는 Page Up: 전진
  - 왼쪽 방향키 또는 Home: 좌회전
  - 아래쪽 방향키 또는 Page Down: 후진
  - 오른쪽 방향키 또는 End: 우회전

키를 놓으면 MANUAL 속도 0 명령을 보내 정지합니다.
STOP 모드는 STOP 버튼으로 선택합니다.

처음 시험할 때는 로버 바퀴가 바닥에서 떨어진 안전한 상태 또는
넓고 비어 있는 장소에서 낮은 속도로 확인합니다.


9. 종료 순서
------------

먼저 웹 지상국을 실행한 터미널에서 Ctrl+C를 누릅니다.

그다음 다음 명령으로 로버의 통신 프로그램을 종료합니다.

  cd ~/LOONARover/GCS
  bash scripts/stop_rover.sh

종료할 로버의 SSH 주소를 입력하고 결과를 확인합니다.

권장 종료 순서:

  1) 로버를 STOP 상태로 만들기
  2) 지상국 실행 터미널에서 Ctrl+C
  3) stop_rover.sh 실행
  4) 모든 종료 결과 확인


10. 다음 실행부터 사용하는 짧은 순서
------------------------------------

매번 다음 순서대로 사용하면 됩니다.

  1) 로버와 지상국 PC를 같은 Wi-Fi에 연결
  2) 로버 IP 확인
  3) bash scripts/start_rover.sh
  4) bash scripts/start_gcs.sh
  5) 웹 지상국에서 TCP CONNECTED와 RX 증가 확인
  6) 사용 후 STOP
  7) 지상국 터미널에서 Ctrl+C
  8) bash scripts/stop_rover.sh


11. 문제가 생겼을 때
--------------------

진단 터미널에서 실패한 항목을 확인합니다.

NETWORK 실패
  - 두 컴퓨터가 같은 Wi-Fi인지 확인합니다.
  - 로버 전원과 IP를 확인합니다.

SSH PORT 또는 SSH LOGIN 실패
  - SSH 주소의 계정과 IP를 확인합니다.
  - 로버에서 SSH 서비스가 실행 중인지 확인합니다.

GROUNDLINK 끊김
  - 로버의 core-cpu1이 실행 중인지 확인합니다.
  - TCP 7443 포트를 확인합니다.

DATA RECEIVED 지연
  - vehicle_gatewayd와 loonar_limo_backend 상태를 확인합니다.
  - RX 숫자가 증가하는지 확인합니다.

ROVER DRIVER 실패 또는 지연
  - limo_base 실행 상태를 확인합니다.
  - /limo_status가 갱신되는지 확인합니다.

영상이 나오지 않음
  - 로버 영상 송신 대상이 현재 지상국 IP인지 확인합니다.
  - 지상국에서 UDP 5600을 사용하는 다른 프로그램이 있는지 확인합니다.


12. 개별 실행 명령
------------------

진단 화면만 실행:

  bash scripts/start_diagnostics.sh --host 192.168.1.50

영상 수신만 실행:

  bash scripts/start_video.sh

실제 로버용 웹 지상국만 직접 실행:

  python3 -B -m webui.server --real-host 192.168.1.50

위 명령의 IP는 항상 현재 로버 IP로 바꿉니다.

웹 서버를 직접 실행하면 진단 터미널과 영상 창은 자동으로 열리지 않습니다.
세 화면을 함께 열려면 scripts/start_gcs.sh를 사용합니다.
