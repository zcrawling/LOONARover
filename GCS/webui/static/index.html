리액션휠 시험 설정

대기

강도는 ESC 중립 대비 PWM 오프셋(µs)으로 조절합니다. RPM·토크 측정값이 아닙니다. 아래 ‘기본’은 현재 펌웨어 기본값입니다.

입력만 바꾸면 동작하지 않습니다. 정차 후 좌·우 실행을 누르면 해당 설정으로 1회 실행합니다. STOP은 ESC·서보를 중립으로 복귀시킵니다.

시험 설정 · PWM / 시간

각 방향: ESC 1단계 → 2단계 → 중립 → 서보 대기 → 서보 유지 → ESC·서보 중립. 설정은 이번 실행에 적용되며 MCU 재부팅 시 기본값으로 돌아갑니다.
