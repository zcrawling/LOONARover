# September 9 recorded-run analysis

These scripts reproduce the September 9 exploratory analysis. They are not
runtime nodes or a validated estimator. They require the original local dataset
under `data/apriltag_gt/` and write to its `analysis_20260909/` directory.

Run from the repository root with `.venv-icp/bin/python`:

1. `tools/analysis/20260909/analyze_all.py` — bag inventory and paired diagnostics.
2. `tools/analysis/20260909/classify.py` — whole-bag terrain separability experiment.
3. `tools/analysis/20260909/regress_c.py` — nested whole-bag C regression experiment.
4. `tools/analysis/20260909/overview.py` — inventory plots.

`make_report.py` produces the classification report specification; HTML packaging
used the separately installed analytics plugin. The saved reports remain in the
data directory. None of these scripts sends vehicle commands.

New per-trial C windows are generated by `loonar_apriltag.trial_analysis` after
the integrated distance test. The older exploratory regression here uses its
original 1-second protocol; moving the script has not changed its methodology.
