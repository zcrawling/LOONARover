# Camera calibration

`c920_20260909_17mm.json` is the measured C920 calibration from 15 images,
using 17.0 mm checkerboard squares. The AprilTag integrated test defaults to
this file. Capture resolution must match its width and height.

Keep measured calibration files versioned. Select another calibration with
`--calibration PATH`; do not overwrite this measurement with unrelated settings.
